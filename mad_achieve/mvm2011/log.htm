■2011ベスト静止画M@D部門
・“晴れた日”と、『晴れた』ソラ / 軍魔
　ちょうど個人的な挫折に挫けていた時期に公開され、回復するまで心に寄り添ってもらった作品です。ありがとうございました。

・Axis Mundi1-monophony- / アルル
　沢山の日常に熱い血が通っているということが確かに伝わってきたから。彼らの物語について具体的な意味合いは何一つ分からないにも関わらず、その戦いの代償に胸を締めつけられるような気がしました。ployphonyも楽しみにしています。

・ナチュラルボーンチャレンジャー4946 / 合作(伽藍堂天晴＆枝切司＆一本杉)
　シーンとテキストで構成された物語フォーマット、その一つの完成形だと信じます。大上段に構えきった外連味に圧倒されることしきりでした。

・Final Scream Project / 軍魔
　大勢の魅力あるキャラクターたちが、屈託無く所狭しと暴れ回っているということ。それが生き方として羨ましくて仕方ないのでした。

・精&#28789;の挽歌 / airsword05
　五つの色は少女の形を象って、いつかキラキラとした音と光に還っていく。そんな心地好い同期の結晶でした。

・Happy Card / 愛理
　多層レイヤーなカードモーションがぷに絵と相まって、蕩けそうな多幸感を覚えました。

・現夢 / 七薙
　混濁した夢と現を分かつものが言霊だとして。それは頼もしくも容赦ないものだなと感じました。

・ANOTYHER DAY / hinako
　物語から切り離された少女たちの概念は、背景としてのデザインを負いながら偏在していくことで、より強固になるように感じられました。

・エリーゼのために / Jekyll
　彼が声を失ってしまったのは世界がアイコンで構成されたコラージュに見えてしまったから、なんて妄想をしました。

・愛憎マリオネッタ / recoba167
　愛憎の意図に操られているはずの紙人形たちが、実のところ私たちよりも自由に見えるのは何故なのかなと考えさせられました。
